### Link Robins

The web service for Flarum — tools and hands-on help for forum owners.

**Extensions** — Flarum 2, most also 1.8

- **[support](https://github.com/linkrobins/support)**: support tickets, with a private staff view and ban appeals
- **[flarum-wiki](https://github.com/linkrobins/flarum-wiki)**: a wiki inside your forum
- **[warble](https://github.com/linkrobins/warble)**: realtime with no server to run, shared hosting included
- **[chirp](https://github.com/linkrobins/chirp)**: live audio rooms attached to any discussion
- **[birdseye](https://github.com/linkrobins/birdseye)**: server-side forum analytics, no cookies, no JavaScript
- **[referral](https://github.com/linkrobins/referral)**: invite-code referrals
- **[auto-lock](https://github.com/linkrobins/auto-lock)**: lock discussions that have gone quiet
- **[auto-verify](https://github.com/linkrobins/auto-verify)**: verify new users' email on registration
- **[flarum-link-gate](https://github.com/linkrobins/flarum-link-gate)**: hide links to chosen domains behind a permission
- **[flarum-discussion-banners](https://github.com/linkrobins/flarum-discussion-banners)**: info banners above, below and between posts
- **[flarum-badge-labels](https://github.com/linkrobins/flarum-badge-labels)**: badge titles beside their icons
- **[toc](https://github.com/linkrobins/toc)**: a table of contents for long posts
- **[clipboard](https://github.com/linkrobins/clipboard)**: copy buttons on code blocks
- **[post-num](https://github.com/linkrobins/post-num)**: a #N number on every post
- **[OP](https://github.com/linkrobins/OP)**: an OP label on the original poster
- **[font-sizer](https://github.com/linkrobins/font-sizer)**: one slider for the forum's base font size
- **[mobile-logo](https://github.com/linkrobins/mobile-logo)**: your logo in the phone navigation bar
- **[shoutbox](https://github.com/linkrobins/shoutbox)** · **[countdown-widget](https://github.com/linkrobins/countdown-widget)** · **[markdown-widget](https://github.com/linkrobins/markdown-widget)** · **[html-widget](https://github.com/linkrobins/html-widget)**: widgets for fof/forum-widgets-core

**Tools**

- **[flarum-docker](https://github.com/linkrobins/flarum-docker)**: self-hosted Flarum 2 in Docker, with tested backup and restore
- **[mcp-for-flarum](https://github.com/linkrobins/mcp-for-flarum)**: an MCP server that gives AI clients your forum's API
- **[metronome](https://github.com/linkrobins/metronome)**: keeps Flarum's scheduler running on shared hosting
